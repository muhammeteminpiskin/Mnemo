

\# Mnemo



Mnemo, kullanıcıların bilgi kartları (flashcards) oluşturarak düzenli tekrar yapmalarını sağlayan açık kaynaklı bir öğrenme uygulamasıdır.



\## Proje Hakkında



Bu proje, 60 günlük backend ve Git/GitHub öğrenme süreci kapsamında geliştirilmektedir.



Temel amaç, kart ve deste yönetimini destekleyen, yerel çalışabilen ve kullanıcılar arasında deste paylaşımına imkân tanıyan bir uygulama oluşturmaktır.



\## Hedeflenen Özellikler



\- Kart ve deste oluşturma, düzenleme ve silme.

\- SM-2 algoritmasıyla aralıklı tekrar.

\- Kullanıcı hesapları ve güvenli kimlik doğrulama.

\- Kartların yerel olarak çalışılabilmesi.

\- Destelerin yayımlanması, aranması ve indirilmesi.



\## Teknolojiler



\- C#

\- .NET 10

\- ASP.NET Core Web API

\- SQL Server

\- Entity Framework Core

\- Git ve GitHub

\- xUnit



\## Proje Yapısı



\- `Mnemo.Core`: Uygulamanın çekirdek kütüphanesi ve iş kuralları.

\- `Mnemo.Playground`: Çekirdek kütüphaneyi denemek için konsol uygulaması.

\- `Mnemo.sln`: Projeleri bir arada tutan solution dosyası.



\## Geliştirme Durumu



Proje aktif geliştirme aşamasındadır. Özellikler müfredat boyunca aşamalı olarak eklenecektir.
